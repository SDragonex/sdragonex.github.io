Kromě hlavních komerčních a studijních systémů udržuji několik menších open-source projektů, automatizačních skriptů a soutěžních her:

---

## Sigma Útulek

Webový portál vyvinutý pro podporu adopce opuštěných zvířat. Cílem projektu je poskytnout moderní, přívětivé a přehledné rozhraní pro prohlížení zvířat v péči útulku s filtrováním podle věku, velikosti a potřeb péče.

* **Technologie:** HTML5, CSS3, Moderní JavaScript, otevřená licence GPLv3.
* **Repozitář:** [GitHub: SDragonex/sigma-utulek](https://github.com/SDragonex/sigma-utulek)

---

## IMG-Scraper

Výkonný konzolový nástroj a skript v Pythonu pro dávkové stahování, indexování a organizaci obrazových souborů z webových zdrojů.

* **Klíčové funkce:** Paralelní asynchronní stahování, filtrace podle rozměrů a formátů, automatické pojmenování a organizace do složek.
* **Technologie:** Python 3, Web Scraping, HTTP Requests.
* **Repozitář:** [GitHub: SDragonex/IMG-Scraper](https://github.com/SDragonex/IMG-Scraper)

---

## VAPO Zahrady

Webová prezentace a realizace portfolia pro profesionální zahradnické služby a zahradní architekturu.

* **Technologie:** Responzivní webový design, optimalizace pro mobilní zařízení, CSS Grid/Flexbox.
* **Repozitář:** [GitHub: SDragonex/vapo](https://github.com/SDragonex/vapo)

---

## Piškvorky (Tour de App)

Soutěžní síťový herní systém vyvinutý pro prestižní celostátní studentskou soutěž Tour de App. Projekt kombinuje jednoduchost logické hry s přísnými nároky na architekturu, kontejnerizaci a rychlost API rozhraní.

* **Architektura:** Kontejnerizované prostředí Docker, backend postavený na frameworku Flask, lehká perzistentní databáze SQLite a zabezpečená REST API gateway.
* **Repozitář:** [GitHub: SDragonex/TdA25-HVD-Design](https://github.com/SDragonex/TdA25-HVD-Design)
