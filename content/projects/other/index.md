In addition to major production systems, I develop and maintain a variety of focused open-source utilities, automation scripts, and competition game systems:

---

## Sigma Shelter (Sigma Útulek)

A web portal engineered to streamline pet adoption for local rescue shelters. The application provides an intuitive animal directory featuring age, size, and care-requirement filtering.

* **Technology:** Semantic HTML5, CSS3, Modern JavaScript, GPL-3.0 License.
* **Repository:** [GitHub: SDragonex/sigma-utulek](https://github.com/SDragonex/sigma-utulek)

---

## IMG-Scraper

A specialized Python command-line utility for high-throughput batch extraction and organization of remote imagery.

* **Key Features:** Parallel downloads, dimension/aspect filtering, automated naming conventions, and file integrity validation.
* **Technology:** Python 3, Web Scraping, HTTP Requests.
* **Repository:** [GitHub: SDragonex/IMG-Scraper](https://github.com/SDragonex/IMG-Scraper)

---

## VAPO Gardens (VAPO Zahrady)

Commercial web portfolio and client landing page showcasing professional landscape design and garden maintenance services.

* **Technology:** Responsive Web Design, Mobile Optimization, CSS Grid/Flexbox.
* **Repository:** [GitHub: SDragonex/vapo](https://github.com/SDragonex/vapo)

## Gomoku Engine (Tour de App)

A network multiplayer logic game developed for the Tour de App coding competition. Designed with strict performance, containerization, and clean architectural criteria.

* **Architecture:** Containerized Docker environment, Python Flask backend, SQLite persistence layer, and REST API gateway.
* **Repository:** [GitHub: SDragonex/TdA25-HVD-Design](https://github.com/SDragonex/TdA25-HVD-Design)
